CIS 258 – HouseBid Full-Stack Development Project

This repository contains my work from CIS 258, where I developed features for the HouseBid application, a full-stack project focused on building a housing bidding and listing platform.

The project involved creating backend functionality and structured APIs that allow users to interact with housing data, including creating listings, retrieving property information, and managing bid-related data. Development focused on building clean, maintainable server-side code while organizing the project into a scalable backend structure.
